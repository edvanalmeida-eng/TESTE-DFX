# linkedin/

Pasta de trabalho do LinkedIn. Só este README vai para o git (repositório público);
todo o resto é pessoal e fica ignorado.

| Pasta | Para quê |
|---|---|
| `perfil/` | headline, sobre, experiência, skills, destaque, banner |
| `voz/` | `voice.md` (as skills leem `~/.claude/linkedin/voice.md`) |
| `posts/ideias` → `rascunhos` → `aprovados` → `publicados` | funil de posts (nada sai sem aprovação) |
| `carrosseis/` | roteiros e PDFs de carrossel |
| `comentarios/` | comentários para fazer em posts de outros |
| `mensagens/recrutadores`, `mensagens/conexoes` | DMs e convites |
| `vagas/` | candidaturas e acompanhamento |
| `fotos/` | suas fotos: perfil, banner, obras, portfólio (veja `fotos/LEIA-ME.md`) |
| `portfolio/` | resumo de obras sem CPF, valores nem nomes de terceiros |
| `analytics/` | números de posts e visitas, para o `li-audit` |
| `plano/` | plano semanal do `li-plan` |

Skills: `li-profile`, `li-plan`, `li-post`, `li-carousel`, `li-repurpose`, `li-comment`,
`li-reply`, `li-dm`, `li-inbox`, `li-audit`, `li-human` (sempre com `--lexicon slop.pt-br.json`).
